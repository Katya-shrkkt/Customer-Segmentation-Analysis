# Customers Segmentation Analysis (SQL)
## Project Overview

This project analyzez customer data using SQL to answer commo business questions about customer demographic, income, and spending behavior.
The analysis was performed using a customer dataset containing demographic and financial information.

---

# Dataset

The dataset includes the following fields:

- Customer ID
- Gender
- Age
- Annual Income ($)
- Spending Score (1-100)
- Profession
- Work Experience
- Family Size

---

## Business Questions

The project answers the following questions:

- How many customers are in database?
- What is the average customer age?
- What is the gender distribution?
- Which profession has the highest average spending score?
- What is the average annual income?
- Which profession has the highest aberage annual income?
- Does family size affect spending score?
- Who are the top 10 customers by spending score?
- Who are the top 10 customers by annual income?
